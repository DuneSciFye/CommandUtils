# Broadcast Message

Usage: /broadcastmessage \<Message>

* Message - The message to send

Color codes use `&`, and PlaceholderAPI placeholders are parsed per player, so `%player_name%` shows each player their own name.

To message only some players, use [Send Message](send-message.md).

### Examples

```
/broadcastmessage &6[Event] &fThe boss has spawned!
```

```
/broadcastmessage &aWelcome back, &e%player_name%&a!
```
