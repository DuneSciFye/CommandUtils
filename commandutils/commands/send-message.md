# Send Message

Usage: /sendmessage \<Player> \<Message>

* Player - The player to message
* Message - The text to send

Colour codes use `&`, and PlaceholderAPI placeholders are parsed against the receiving player.

To reach everyone, use [Broadcast Message](broadcast-message.md); for one line above the hotbar, [Send Action Bar](send-action-bar.md).

### Examples

```
/sendmessage Steve &aQuest complete!
```

```
/sendmessage Steve &7You have &e%vault_eco_balance%&7 coins.
```
